EXPENSE TRACKER

PROJECT OVERVIEW

==> THE EXPENSE TRACKER IS A PYTHON-BASED APPLICATION DESIGNED TO RECORD,MANAGE,AND MONITOR DAILY EXPENSES.
   IT HELPS USERS MAINTAIN ORGANIZED EXPENSE RECORDS AND TRACK THEIR SPENDING EFFICIENTLY.

TECHNOLOGIES USED

=> PYTHON PROGRAMMING 
=> DATABASE : MYSQL
=> DATABASE CONNECTOR : MYSQL CONNECTOR
=> IDE : PYCHARM
=> DATABASE TOOL : MYSQL WORKBENCH

KEY FEATURES

-> ADD NEW EXPENSE RECORDS
-> VIEW ALL EXPENSE DETAILS
-> UPDATE EXISTING EXPENSE RECORDS
-> DELETE EXPENSE RECORDS
-> CATEGORIZE EXPENSES
-> CALCULATE TOTAL EXPENSE
-> STORE AND MANAGE EXPENSE RECORDS IN MYSQL.

EXPENSE INFORMATION

* EXPENSE ID
* EXPENSE NAME
* CATEGORY
* AMOUNT
* EXPENSE DATE
* DESCRIPTION

DATABASE MANAGEMENT

==> MYSQL IS USED TO STORE AND MANAGE EXPENSE RECORDS.
   PYTHON CONNECTS TO THE DATABASE USING MYSQL CONNECTOR TO PERFORM CRUD OPERATIONS.

CORE CONCEPTS IMPLEMENTED

* PYTHON FUNCTIONS AND MODULES
* MYSQL DATABASE CONNECTIVITY
* CRUD OPERATIONS
* SQL QUERIES
* EXCEPTIONAL HANDLING
* INPUT VALIDATION

PROJECT OBJECTIVE 

==> TO DEVELOP A SIMOLE AND EFFICIENT EXPENSE MANAGEMENT APPLICATION THAT HELPS USER MONITOR THEIR DAILY SPENDING,
    ORGANIZE FINANCIAL RECORDS,AND UNDERSTAND THEIR EXPENSE PATTERNS.
